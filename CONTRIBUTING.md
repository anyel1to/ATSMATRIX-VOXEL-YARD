# Contributing

Voxel Yard is an ATSMATRIX reference floor. Small, precise patches are welcome.

## Rules

1. Keep the yard a single `index.html` unless a split is required for a real tick adapter.
2. Do not add a bundler or package manager for cosmetic reasons.
3. Simulation values stay labeled as simulation until a live bus exists.
4. Match existing naming: NYX, VEX, RIO, KAI, ORA, ZEN and the six towers.
5. MIT license on all original contributions.

## Patch flow

1. Fork and branch from `main`.
2. Run locally with `python3 -m http.server 4173`.
3. Open a pull request with what changed and how you tested it.
